# UI icon attribution

`assets/ui-icons.json` contains 12 vector outlines extracted from the fonts
distributed with QtAwesome 1.4.1. The outlines are unchanged; extraction and
JSON serialization replace the font runtime. No font files are distributed.

| Remix Icon 2.5.0 | sd-card-line | Apache-2.0; Copyright (c) Remix Design; https://github.com/Remix-Design/RemixIcon/tree/v2.5.0 |
| Material Design Icons 5.9.55 | check, minus, alert-outline | Apache-2.0; Pictogrammers / Templarian; https://github.com/Templarian/MaterialDesign |
