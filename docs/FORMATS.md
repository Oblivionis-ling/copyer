# 格式与日期

| 类型 | 扩展名 | 日期依据 |
| --- | --- | --- |
| RAW | 25 种，见下表 | EXIF / 厂商拍摄时间 → 内容创建时间 → 修改时间 |
| 照片 | `.jpg` `.jpeg` `.heic` `.heif` `.hif` | EXIF / XMP 拍摄时间 → 内容创建时间 → 修改时间 |
| 视频 | `.mp4` `.mov` `.m4v` | 拍摄字段（如 Apple CreationDate）→ XMP / 容器创建时间 → 修改时间 |

| 厂商 / 格式 | RAW 扩展名 |
| --- | --- |
| 佳能 | `.crw` `.cr2` `.cr3` |
| 尼康 | `.nef` `.nrw` |
| 索尼 | `.arw` `.srf` `.sr2` |
| 富士 / 奥林巴斯及 OM SYSTEM | `.raf` / `.orf` |
| 松下 | `.rw2` `.raw` |
| 宾得 / 三星 | `.pef` / `.srw` |
| 哈苏 / 徕卡 | `.3fr` `.fff` / `.rwl` |
| 适马 / 美能达 | `.x3f` / `.mrw` |
| Phase One / Leaf | `.iiq` `.mos` |
| 柯达 | `.dcr` `.kdc` `.k25` |
| 通用 DNG（含 DJI、Apple ProRAW） | `.dng` |

扩展名不区分大小写。只读取元数据，不解码影像或加载缩略图。

JPEG、TIFF 结构 RAW、Canon CR3、Fujifilm RAF、Minolta MRW 和 HEIF 会先尝试读取标准 EXIF 拍摄日期及其子秒和时区。Canon CRW 读取 CIFF 拍摄时间，Sigma X3F 优先读取内嵌 EXIF，其次读取相机记录的拍摄时间。其余无法直接读出可靠日期的文件与视频由 ExifTool 批量解析。

带时区的拍摄日期保留拍摄地的日历日期。QuickTime 的整数容器日期按规范应为 UTC，但部分相机会写本地时间：遇到这种设备，在设置中关闭“视频容器时间按 UTC 转为本机时间”，然后重新扫描。文件没有有效元数据时，无法恢复原本的拍摄时间，将使用文件修改时间归档。

## 导入规则

- 默认只复制，保留源文件。复制成功后保留文件修改时间等常规元数据。点击“删除已校验的源文件”立即开始永久删除。程序会根据导入时的校验记录检查两端文件是否仍在原位且属性一致。
- 每个文件先写入目标目录下的 `.copyer-*.part`，回读校验通过后才使用正式文件名。
- 同名且内容不同，追加 `_1`、`_2` 等编号；关闭“跳过内容完全相同的文件”后，同内容也会生成编号副本。
- 重复比较仅检查当前日期目录中的同名及递增编号候选，不是跨目录全库查重。
- 取消会清理本次未完成的临时文件。突然断电或进程被强制终止可能留下 `.part`；它不会被当成正式文件。
- 来源与目标不能相同，目标也不能位于来源目录内。扫描跳过链接和重解析点，使用目录枚举已有的大小和修改时间供导入前快速比对。导入时再打开文件确认身份，并验证文件内容。
- 重试记录限当前会话；关闭程序后，重新扫描可以通过内容比较跳过已经导入的同名文件。
- 进度包含“复制 + 校验”两份字节工作量，100% 表示全部选中文件已完成或验证为相同文件。速度也包含校验读取，不代表纯写盘速度。
