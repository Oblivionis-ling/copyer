# Copyer v1.5.1

补全 RAW 和视频的日期读取，增加 RAW 与 iPhone 照片格式覆盖。

- RAW 从 8 种扩展到 25 种扩展名，包含佳能 CR3、DJI / Apple ProRAW 的 DNG，以及 CRW、NRW、PEF、SRW、3FR、X3F 等。
- 新增 HEIC、HEIF、HIF；原“JPEG”选项更名为“照片”，保留已有选择偏好。
- 使用内置 ExifTool 读取拍摄日期；iPhone MOV 优先使用带时区的拍摄字段，保留拍摄地日期。
- 无时区的视频容器日期默认按 UTC 转为本机时间；设备写入本地时间时可在设置中关闭转换。
- 明细显示具体日期来源，悬停可查看字段和值；元数据缺失、文件损坏或读取器缺失时明确说明回退。
- 单次扫描复用读取进程，支持取消和超时；保持只读及原有 SHA-256 复制校验。

64 项检查：61 项通过，3 项因 Windows 符号链接权限跳过。10 种 RAW 使用真实元数据测试样本；HEIF 和视频的 Apple/DJI 字段测试包含受控生成的案例，尚未使用用户设备原片验收。

文件缺少有效拍摄日期时无法还原，仍需使用修改时间。视频经过编辑或导出后，容器创建日期可能不再是原始拍摄日期。影像预览仍仅支持 JPEG。

便携包：`Copyer-v1.5.1-Windows-x64.zip`。完整解压，运行 `copyer-1.5.1.exe`，保留同目录的 `_internal` 文件夹。
