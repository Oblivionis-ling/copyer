# Copyer v1.5.0

Windows 照片与视频导入工具。本版重构白灰玻璃界面，并补全文件选择、进度、取消、重试与复制校验。

## 更新

- 新增纯白灰双页图标；主界面使用细线网格、玻璃控件与透明窗框，默认尺寸为 700 × 526 逻辑像素。
- 统一主界面、设置和提示窗口；用浅灰反馈替代黑色焦点框，设置正文为 16px。
- 支持全选、按日期及逐文件选择，自动识别日期并填写自定义后缀；JPEG 可查看预览。
- 后台扫描和导入，显示复制与校验进度、速度及预计剩余时间；支持取消、继续未完成项和失败重试。
- 先写入临时文件，再进行 SHA-256 回读校验；同名不同内容自动编号，同名相同内容可跳过。移除删除源文件功能。
- 保留“减少透明度”“减少动态效果”选项。

## 下载与运行

下载附件 **Copyer-v1.5.0-Windows-x64.zip**，完整解压后运行 `copyer-1.5.0/copyer-1.5.0.exe`。请保留同目录的 `_internal` 文件夹，无需安装 Python。

附件 `SHA256SUMS.txt` 用于核对压缩包完整性。源码见本次 `v1.5.0` 标签。

## 验证与边界

- 44 项测试：41 项通过，3 项因 Windows 符号链接权限不足跳过；便携包构建、启动和图标资源核验通过。
- JPEG 优先使用 EXIF 拍摄时间；RAW、视频使用文件修改时间，暂不解码预览。
- 去重限目标日期目录内的同名及编号候选文件；重试记录限当前会话。
- 玻璃效果由 Windows/Qt 绘制。真实读卡器热拔插和掉电恢复尚未验证。
