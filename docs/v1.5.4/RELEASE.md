# Copyer v1.5.4

- **扫描提速**：JPEG、HEIF 和 RAW 优先直接读取拍摄日期。不解码图像，不加载缩略图。新增 Canon CRW 的 CIFF 拍摄时间和 Sigma X3F 的内嵌 EXIF、相机拍摄时间读取。无法直接读出可靠日期的文件与视频由 ExifTool 批量处理。
- **导入复核**：导入时确认源文件身份，复制后回读目标副本并核对 SHA-256。再次扫描时复用目录属性和同次运行中未变化文件的日期。
- **快速删除源文件**：点击“删除已校验的源文件”即开始，按文件数显示进度。只处理本次已校验且两端文件属性仍符合导入记录的源文件。删除不经过回收站，删除阶段不再回读内容。

本机使用 10 种 RAW 元数据样本组成的 300 个文件做首次扫描对照。全部使用 ExifTool 时中位耗时 3.26 秒，1.5.4 为 0.06 秒，日期分组和时间信息一致。样本规模与存储介质会影响实际速度。

1.5.3 用户可在设置中检查更新。也可下载 Windows x64 便携包，完整解压后启动 `Copyer.exe`，保留同目录的 `_internal`。
