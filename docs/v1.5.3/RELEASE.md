# Copyer v1.5.3

- **界面精简**：移除文件明细、缩略图页面和入口，保留按日期选择；主页面固定使用紧凑控件比例，大窗口不再放大整套控件。
- **设置页**：在主窗口内切换，修改后自动保存，点击“返回”继续原任务；缩小字号，正文和按钮 13px、标题 14px。
- **检查更新**：设置中检查 GitHub 正式版本。确认更新后，便携版会自动下载、校验并重启；没有新版时直接提示已是最新版本。
- **校验后清理来源**：导入完成后，主页面显示“删除已校验的源文件”。确认前可查看文件清单，删除前会再次校验两端内容。已变化、未完成或校验失败的文件保留。删除不经过回收站，来源文件夹保留。
- **扫描提速**：批量读取日期，缓存同次运行中未变化文件的结果。本机 300 个混合元数据样本首次扫描耗时减少约 23%，再次扫描约 0.27 秒；实际速度受存储卡与素材影响。

完整解压后运行 `Copyer.exe`，保留旁边的 `_internal`。当前 1.5.2 没有更新入口，需要先手动下载此版；1.5.3 起可在设置中更新后续版本。

自动更新只替换程序和 `_internal`，保留同目录其他文件与个人设置。新版本启动确认前保留旧程序；若回退也失败，提示中会给出日志位置。
